# Front-End Assessment - 3-Column Chat Dashboard

A modern, professional 3-column communication dashboard built with **Next.js 15**, **TypeScript**, and **Tailwind CSS**. This project matches the provided Figma design and integrates real dummy API data.

## 📋 Project Overview

- **Figma Design Matched:** A 3-column layout (Left Sidebar, User List, Chat Thread, Right Details Panel).
- **Loading State:** Custom "Extracting Information..." overlay with a spinning gradient ring and blue background.
- **Responsive/Modern UI:** Clean white backgrounds, subtle light-gray borders, and interactive elements.
